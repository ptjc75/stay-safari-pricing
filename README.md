## 用起来怎么样，有几个坑要提前知道

GitHub 上有几篇上手教程提到，脚本从 GreasyFork 一键导入比较顺，广告拦截对国内主流网站效果不错，多设备切换时云同步稳定。这些是使用者的描述，不是官方宣传，可以当作参考。

坑一，视频下载不是万能的。网页视频的加密和防盗链策略各家不同，资源嗅探能解决一部分站点，解决不了另一部分。这不是 Stay 的问题，所有下载类扩展都受同样的限制。冲着“什么视频都能下”去买，大概率会失望。

坑二，App Store 的隐私标签写明开发者可能收集标识符，用于跨 App 和网站的追踪。介意这个的，可以在系统设置里关掉 App 追踪权限，或者干脆只用免费版。

坑三，Pro 的功能里，深色模式和下载是感知最强的，自定义过滤规则、标记广告、下载隐私模式属于用得上就值、用不上就闲置的类型。别被功能列表的长度说服，对着自己的使用习惯看。

还有一点，这软件的更新节奏不算慢，但功能边界基本定型了。它不会突然变成另一个产品，你现在看到的功能列表，大概率就是它长期的样子。
